# TokensBar build21：四页界面精修

沿用原字体与原有功能，在 build20 候选版上直接改进；没有合并 main 或发布新版本。

- 趋势：原先大数字、模型差额和长段口径说明挤在同一层级，缺少视觉分组。现在以淡墨绿摘要卡突出变化，今日与此前七日日均左右对照；模型贡献独立成卡，口径、未完结 UTC 日和更新时间降为辅助信息。没有把 token 变化当成账单变化或原因推断。
- 数据状态：原先服务端与本机状态主要靠段落区分，时间和行动不够集中。现在拆成服务端、此 Mac 两张卡，最近尝试／成功读取／服务端提交分别对齐；主操作用墨绿，次操作用浅绿。保留旧数值、刷新不上传活动等重要边界没有删掉。
- 菜单栏：原先只有勾选和上下移动，修改后的组合不够直观。增加即时组合预览，费用和排名明确是占位；选择区与预览分开，绿色选中状态，重新绘制清晰勾选符号并补足按钮内边距。至少一项保护、顺序持久化保持不变。
- 提醒：原先阈值、频率、保存和解释文字混在一起。现在拆为阈值和通知两组，数字框右对齐，主按钮写清“保存提醒设置”；保留填 0 关闭、费用估算、旧数据不触发、专注模式可能隐藏横幅的说明。

四页的选中标签、主按钮和高亮固定采用墨绿／深绿；浅深色分别调整背景、卡片边界及辅助绿色文字。设置主标题改为“用量与显示”，避免原来宣传式大标题抢过实际内容。保留原生弹出菜单、键盘／无障碍标签与焦点指示。

验证与限制：提供实际 macOS App 的 2× 离屏渲染图，使用演示数据，不是设计稿或放大旧图。原主面板与 Agent 自动来源能力未扩展；真实登录账号、Keychain/OpenRouter、通知横幅实际送达仍未实测。候选 App 仅 ad-hoc 签名，未 Apple 公证，首次运行可能被 macOS 拦截。
